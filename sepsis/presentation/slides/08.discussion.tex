\begin{frame}{VII. Discussion: The Central Lesson and Limitations}
\begin{atucols}[t]
\begin{column}{0.50\textwidth}
\textbf{The Sepsis-3 label on MIMIC-IV:}
\begin{enumerate}\itemsep2pt\scriptsize
  \item \textbf{Depends on clinical action for membership.} The empty
        pre-treatment window belongs to the onset rule: standard timing moves
        \pcFNMovedEarlier{} onsets earlier, \pcFNBeforeAnchorTest{} of them
        into the test set's pre-treatment window (onset-hour separability, not
        advance warning).
  \item \textbf{Is sensitive to how it is defined.} Cases nearly double across
        readings ($\kappa = \pcKappaVsBA$), yet AUROC moves by only
        \pcSpreadLabel.
  \item \textbf{Produces unusable alert behaviour.} No operating point comes
        near the 1.4 benchmark; the best under B costs
        \pcUtilityOptBurdenGbtB{} false alerts per true one.
\end{enumerate}
\vspace{2pt}
\begin{alertblock}{}
  \scriptsize These problems are independent of model complexity. Addressing
  them requires changing the label, not only the model.
\end{alertblock}
\end{column}
\begin{column}{0.48\textwidth}
\textbf{Key limitations}
\begin{itemize}\itemsep2pt\scriptsize
  \item \textbf{Current-hour estimand:} detection at the recorded onset, not
        advance warning.
  \item \textbf{External validation is bounded by label transport:}
        \pcExtMicroCoverage\% culture coverage, \pcExtNEventsB{} events under B.
  \item \textbf{Single-centre development}, with a selected base cohort
        (first stays, $\geq 4$\,h).
  \item \textbf{The pre-registered onset rule is not the standard one}; F
        restores it post hoc.
  \item \textbf{Variant D is not a validated construct}; its components
        overlap the model inputs.
  \item \textbf{Post-hoc protocol amendments} are disclosed as such; the
        literature search is narrative, not systematic.
\end{itemize}
\end{column}
\end{atucols}
\end{frame}
